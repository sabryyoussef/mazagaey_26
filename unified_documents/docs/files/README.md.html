📄 Unified Documents Extension

A comprehensive document management system for Odoo 18 that extends the native Documents module with advanced functionality for products, projects, and business workflows.

🎯 Key Features

  • Enhanced Document Management: Category classification, status tracking, and priority management
  • Product Integration: Document linking and management for products and services
  • Project Integration: Automated document workflows for projects
  • Smart Automation: Rules-based document copying and management
  • Interactive Wizards: User-friendly interfaces for complex operations

🚀 Installation

Prerequisites

  • Odoo 18.0 or higher
  • Odoo Enterprise (for Documents module)
  • Python 3.8+

Installation Steps

  1. Copy the module to your Odoo addons directory
  2. Update the addons list in Odoo
  3. Install the "Unified Documents Extension" module
  4. Configure user groups and permissions
# Add to addons path addons_path = /path/to/odoo/addons,/path/to/custom_addons # Update module list python3 odoo-bin -u all -d your_database

🔧 Configuration

User Groups

The module creates three user groups for different access levels:

  • Unified Documents User: Basic document operations
  • Unified Documents Manager: Advanced management features
  • Unified Documents Admin: Full administrative access

Document Categories

Documents are classified into four main categories:

  • Required: Mandatory documents for processes
  • Deliverable: Output documents for clients
  • Reference: Supporting documentation
  • Compliance: Regulatory and legal documents

📖 Usage Guide

Document Management

Navigate to Project → Documentation → Document Management to access the main document management interface.

Product Documents

In product forms, use the Documents tab to manage product-related documents and copy them to projects.

Project Documents

Projects automatically get document folders and can receive documents from products or other sources.

Automation Rules

Configure automation rules in Documentation → Document Copy Automations to automatically copy documents based on conditions.

🔧 Development

Module Structure

  • models/: Business logic and data models
  • views/: User interface definitions
  • wizard/: Interactive wizards
  • services/: Core business services
  • data/: Configuration and demo data
  • security/: Access rights and permissions

Extending the Module

To extend the module functionality:

  1. Create new models in the appropriate subdirectory
  2. Define views in the views directory
  3. Add security rules in security/
  4. Update the manifest file with new dependencies

🐛 Troubleshooting

Common Issues

  • Documents not appearing: Check user permissions and document categories
  • Automation not working: Verify automation rules and conditions
  • Permission errors: Ensure proper user group assignments
