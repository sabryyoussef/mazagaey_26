🏗️ Architecture Structure

Models Directory Organization

models/
├── __init__.py          # This file - loads all sub-modules
├── core/               # Core document management
│   ├── __init__.py
│   ├── documents_document.py
│   ├── document_copy_automation.py
│   └── document_management.py
├── integrations/       # Integration with other modules
│   ├── __init__.py
│   ├── product_extension.py
│   ├── project_extension.py
│   ├── sale_order_extension.py
│   └── purchase_order_extension.py
└── extensions/         # Extensions to existing models
    ├── __init__.py
    ├── ir_attachment_extension.py
    ├── task_extension.py
    └── user_extension.py

🔧 Loading Strategy

  • Core First: Core models load first to establish base functionality
  • Extensions Second: Extensions load to modify existing Odoo models
  • Integrations Last: Integrations load last to connect with other modules
  • Dependency Management: Each sub-module manages its own dependencies

🎯 Design Principles

  • Separation of Concerns: Each directory has a specific responsibility
  • Modularity: Easy to add/remove functionality
  • Maintainability: Clear structure for easy maintenance
  • Scalability: Easy to extend with new features

📁 Sub-Module Responsibilities

  • core/: Contains the main business logic for document management
  • integrations/: Handles connections with products, projects, sales, etc.
  • extensions/: Modifies existing Odoo models to add functionality
