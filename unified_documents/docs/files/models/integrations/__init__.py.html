🔗 Integration Models Architecture

product_extension.py

Purpose: Extends product.template and product.product models with document management capabilities

Key Features:

  • Document count fields and smart buttons
  • Document template linking and management
  • Document copying to projects functionality
  • Product-specific document workflows
  • Document upload and attachment handling

project_extension.py

Purpose: Extends project.project model with document management and automation

Key Features:

  • Automated project folder creation
  • Document count tracking and display
  • Project document workflows
  • Document assignment and organization
  • Project-specific document templates

sale_order_extension.py

Purpose: Integrates document management with sales processes

Key Features:

  • Sales order document automation
  • Quote and contract document management
  • Customer document workflows
  • Sales process document tracking
  • Automated document generation

purchase_order_extension.py

Purpose: Integrates document management with purchase processes

Key Features:

  • Purchase order document automation
  • Vendor document management
  • Procurement document workflows
  • Purchase process document tracking
  • Supplier document templates
