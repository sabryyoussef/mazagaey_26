# ⚡ Quick Start Guide - Dynamic Quotation System

## 🚀 **5-Minute Test with Demo Data**

### **Step 1: Install & Access (1 minute)**
1. **Install FSM Workflow module** with demo data
2. **Navigate to**: FSM Workflow → Workflow Instances
3. **You'll see 2 demo projects ready to test**
4. **Note**: Projects will be in "Running" state (not "Draft")

### **Step 2: Test Construction Project (2 minutes)**

#### **Quick Test 1: Checkpoint Quotation**
1. **Click**: "ABC Construction - Office Building Project"
2. **Click**: "Open Project" → **"Configuration" tab** → **"Milestones"**
3. **Click**: "Foundation Complete" milestone
4. **Go to**: "Checkpoints" tab in milestone form
5. **Mark**: "Foundation Poured" as reached ✅
6. **Result**: ✅ **Quotation automatically created!**

#### **Quick Test 2: Milestone Quotation**
1. **Mark**: "Foundation Inspection Passed" as reached ✅
2. **Result**: ✅ **Milestone reached + quotation created!**

### **Step 3: Verify Results (1 minute)**
1. **Go to**: Sales → Quotations
2. **Look for**: 2 new quotations with workflow links
3. **Check**: Trigger types show "Checkpoint Reached" and "Milestone Reached"

### **Step 4: Test Manual Creation (1 minute)**
1. **Go back to**: Workflow Instance
2. **Click**: "Create Quotation" button
3. **Add line**: Any service for $1000
4. **Save**: ✅ **Manual quotation linked to workflow**

## 🆘 **If Something Doesn't Work**

### **No quotations created?**
- Check: Workflow has a partner assigned
- Check: Checkpoints have quotation triggers enabled
- Check: Quotation templates exist

### **Templates not applying?**
- Check: Demo products exist in system
- Check: Template lines have valid products

### **Workflow not linking?**
- Check: Sale order extension is installed
- Check: All dependencies are installed
