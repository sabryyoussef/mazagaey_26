# 🧭 Navigation Guide - Accessing Milestones & Checkpoints

## 📍 **Step-by-Step Navigation Path**

### **Step 1: Access Workflow Instances**
```
Odoo Home → FSM Workflow → Workflow Instances
```

### **Step 2: Open Project**
```
Workflow Instance → Click "Open Project" button (🔧 icon)
```

### **Step 3: Access Milestones**
```
Project Form → "Configuration" tab → Click "Milestones"
```

### **Step 4: Open Milestone**
```
Milestones List → Click on specific milestone (e.g., "Foundation Complete")
```

### **Step 5: Access Checkpoints**
```
Milestone Form → "Checkpoints" tab
```

## 🔍 **Alternative Navigation Methods**

### **Method 1: Direct Milestone Access**
```
Project → Configuration → Milestones → [Milestone Name]
```

### **Method 2: Smart Button Access**
```
Project → Look for "Milestones" smart button (if available)
```

### **Method 3: Menu Access**
```
Project → Project → Milestones (if menu item exists)
```

### **Step 1: Workflow Instances List**

## 🚨 **Common Issues & Solutions**

### **Issue: Can't find Configuration tab**
- **Solution**: Make sure you're in the project form, not the workflow instance form
- **Check**: Look for tabs at the bottom of the form

### **Issue: No Milestones visible**
- **Solution**: Check if milestones exist for the project
- **Check**: Verify project has milestones assigned

### **Issue: Can't access Checkpoints**
- **Solution**: Make sure you're in the milestone form, not the project form
- **Check**: Look for "Checkpoints" tab in the milestone

### **Issue: Checkpoints not showing**
- **Solution**: Check if checkpoints exist for the milestone
- **Check**: Verify milestone has checkpoints assigned
