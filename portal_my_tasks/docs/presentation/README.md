# Portal My Tasks - Presentation Files

## How to Open in PowerPoint

### Method 1: Open HTML File Directly
1. Open Microsoft PowerPoint
2. Go to **File** → **Open**
3. Navigate to this folder
4. Select `PORTAL_MY_TASKS_USER_GUIDE.html`
5. PowerPoint will convert the HTML to slides
6. Each `<div class="slide">` becomes a separate slide

### Method 2: Import HTML
1. Open PowerPoint
2. Go to **File** → **Open**
3. Change file type filter to "All Files" or "Web Pages"
4. Select the HTML file
5. PowerPoint will create slides from the HTML structure

### Method 3: Copy Content
1. Open the HTML file in a web browser
2. Use PowerPoint's **Insert** → **Screenshot** or **Screen Clipping** to capture slides
3. Or copy sections and paste into PowerPoint slides
