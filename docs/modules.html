Level 3 - Core Features

unified_documents

Product-based document automation and lifecycle management

Key Features

  • ✅ Product-specific document configuration
  • ✅ Required documents (from customer)
  • ✅ Deliverable documents (to customer)
  • ✅ Complete workflow: Draft → Upload → Complete → Confirm → Done
  • ✅ Return workflow with notes
  • ✅ Automatic folder structure creation
  • ✅ Expiry date tracking and reminders

Main Models

documents.document (Extended)
├─ required_project_id: Project needing this doc
├─ deliverable_project_id: Project delivering this doc
├─ state: Draft/Uploaded/Complete/Confirmed/Done
├─ expiration_date: Document expiry
├─ return_notes: Return reason
└─ type_id: Document type

product.template (Extended)
├─ required_document_ids: Documents needed from client
│   ├─ document_type_id: Type (Passport, etc.)
│   ├─ expiration_required: Track expiry?
│   └─ is_mandatory: Required or optional
└─ deliverable_document_ids: Documents to deliver
    ├─ document_type_id: Type (License, etc.)
    └─ milestone_id: When to create

Document Workflows

Required Documents (From Client)

1. Auto-created on project start
   └─> state = 'draft'
   
2. Client uploads document
   └─> state = 'uploaded'
   
3. Document controller reviews
   └─> Click "Complete Required"
   └─> state = 'complete'
   
4. Project manager approves
   └─> Click "Confirm Required"
   └─> state = 'confirmed'
   
   OR return if issues:
   └─> Click "Return Required"
   └─> Add return notes
   └─> state = 'draft'

Deliverable Documents (To Client)

1. Auto-created at milestone
   └─> state = 'draft'
   
2. Service team uploads finals
   └─> Click "Complete Deliverable"
   └─> state = 'complete'
   
3. Quality check
   └─> Click "Confirm Deliverable"
   └─> state = 'confirmed'
   └─> Ready for handover

UAE Document Types

  • Required: Passport, Emirates ID, Proof of Address, Bank Reference, Business Plan
  • Deliverable: Trade License, MOA, Share Certificates, Certificate of Incorporation

Dependencies

documents (Enterprise), project_templates_basic

Level 5 - Compliance

project_compliance

KYC/AML compliance, shareholder registry, and UBO calculation

Key Features

  • ✅ Multi-factor risk assessment framework
  • ✅ Shareholder registry with ownership tracking
  • ✅ Automatic UBO (Ultimate Beneficial Owner) calculation
  • ✅ Compliance onboarding workflows
  • ✅ Document requirements by risk level
  • ✅ PEP (Politically Exposed Person) screening
  • ✅ Sanctions checking

Main Models

initial.client.onboarding
├─ partner_id: Customer
├─ state: Draft/Submitted/Validated/Approved
├─ risk_rating: Low/Medium/High
├─ service_risk/product_risk/client_risk: Risk scores
├─ geography_risk/pep_risk/sanction_risk
├─ adverse_media_risk
└─ overall_risk_score: Computed

res.partner.shareholder
├─ partner_id: Company
├─ shareholder_id: Shareholder (individual/company)
├─ ownership_percentage: % owned
├─ is_direct: Direct or indirect ownership
├─ is_ubo: Ultimate Beneficial Owner?
└─ ubo_percentage: Computed total ownership

project.project (Extended)
├─ compliance_onboarding_id: Linked onboarding
├─ compliance_required: Boolean
├─ is_complete_compliance: Data complete?
├─ is_confirm_compliance: Compliance approved?
└─ compliance_shareholder_ids: Shareholders

Risk Assessment Framework

Risk Categories:
├─ Service Risk (15%) - Offshore, complex structures
├─ Product Risk (15%) - Banking, crypto, financial
├─ Client Risk (15%) - First-time, complex
├─ Geography Risk (20%) - High-risk jurisdictions
├─ PEP Risk (15%) - Politically exposed
├─ Sanction Risk (10%) - Sanctioned entities
└─ Adverse Media (10%) - Negative news

Rating:
├─ Low Risk: Score < 30
├─ Medium Risk: Score 30-60
└─ High Risk: Score > 60

UBO Calculation

Company: Tech Innovations FZCO
Shareholders:
├─> Individual A (40%) → Direct UBO ✓
├─> Company B (35%)
│   ├─> Individual C (60%) → Indirect 21% (below 25%)
│   └─> Individual D (40%) → Indirect 14% (below 25%)
└─> Individual E (25%) → Direct UBO ✓ (exactly at threshold)

Identified UBOs:
1. Individual A (40% direct)
2. Individual E (25% direct)

Document Requirements

  • Low Risk: Passport, proof of address, bank reference
  • Medium Risk: + Source of funds, bank statements (6 months), business plan
  • High Risk: + Source of wealth, audited financials, enhanced due diligence

Critical Gate

IF product.requires_compliance AND not is_confirm_compliance:
    BLOCK project completion
    BLOCK deliverable handover

Dependencies

project_handover_notes
