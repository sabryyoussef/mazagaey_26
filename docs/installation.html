Installation Guide

Step-by-step instructions to install and configure Mazagawy modules

Prerequisites

  • Odoo Version: 18.0 Enterprise Edition
  • Required Base Modules:
    • project (Projects)
    • documents (Documents - Enterprise)
    • sale_management (Sales)
    • hr_timesheet (Timesheets)
    • product (Products)
  • System Requirements:
    • Docker & Docker Compose (if using containerized setup)
    • PostgreSQL 15+
    • Python 3.10+

Installation Order

Modules must be installed in the following order due to dependencies:

Level 1: Foundation (Install First)

Step 1

project_checkpoints_basic

Purpose: Core checkpoint and milestone functionality

Dependencies: project, product

Installation:

# Via Odoo UI
Apps → Search "Project Checkpoints" → Install

# Via command line
./odoo-bin -d your_database -i project_checkpoints_basic

Level 2: Templates (Install Second)

Step 2

project_templates_basic

Purpose: Project and task template management

Dependencies: project_checkpoints_basic, sale_management

Installation:

# Via Odoo UI
Apps → Search "Project Templates" → Install

# Via command line
./odoo-bin -d your_database -i project_templates_basic

Level 3: Core Features (Install in Any Order)

Step 3a

unified_documents

Purpose: Document lifecycle management

Dependencies: documents (Enterprise), project_templates_basic

./odoo-bin -d your_database -i unified_documents
Step 3b

smart_templates

Purpose: AI-powered template recommendations

Dependencies: project_templates_basic

./odoo-bin -d your_database -i smart_templates

Level 4: Handover & FSM (Install in Any Order)

Step 4a

project_handover_notes

Purpose: Company formation data collection

Dependencies: project_templates_basic

./odoo-bin -d your_database -i project_handover_notes
Step 4b

fsm_workflow_quote_v2 (Optional)

Purpose: Field service quotations

Dependencies: project_templates_basic, industry_fsm

./odoo-bin -d your_database -i fsm_workflow_quote_v2

Level 5: Compliance (Install Last)

Step 5

project_compliance

Purpose: KYC/AML compliance and shareholder management

Dependencies: project_handover_notes

./odoo-bin -d your_database -i project_compliance

Docker Installation

If using the provided Docker setup:

1. Clone Repository

git clone https://github.com/sabryyoussef/mazagaey_26.git
cd mazagaey_26

2. Configure Environment

# Edit docker-compose.yml if needed
# Default configuration:
# - PostgreSQL port: 5433
# - Odoo port: 8069
# - Database: odoo
# - User/Password: odoo

3. Start Containers

# Build and start
docker-compose up -d

# Check status
docker ps

# View logs
docker-compose logs -f odoo

4. Access Odoo

# Database manager
http://localhost:8069/web/database/manager

# Create database or use existing
# Default credentials: odoo/odoo

5. Install Modules

Access Odoo UI and install modules in order listed above.

Post-Installation Configuration

1. Configure Document Types

  • Go to Documents → Configuration → Document Types
  • Create required document types:
    • Passport
    • Emirates ID
    • Trade License
    • Memorandum of Association
    • Share Certificates

2. Create Project Templates

  • Go to Projects → Configuration → Workflow Templates
  • Create templates for your services:
    • FZCO Formation
    • FZE Formation
    • Mainland LLC Formation
    • Visa Services

3. Configure Task Templates

  • Go to Projects → Configuration → Task Templates
  • Create task templates with checkpoints for each service phase

4. Set Up Products

  • Go to Sales → Products → Products
  • Create service products
  • Link to project templates
  • Configure required and deliverable documents

5. Configure Compliance Rules

  • Go to Projects → Compliance → Configuration
  • Set up risk assessment criteria
  • Define document requirements by risk level

Verification

Test your installation:

1. Create Test Quotation

1. Sales → New Quotation
2. Add customer
3. Add service product
4. Confirm quotation
5. Verify project auto-created

2. Check Project Structure

1. Open created project
2. Verify tasks created from templates
3. Check documents folder exists
4. Verify checkpoints visible on tasks

3. Test Document Workflow

1. Go to Documents
2. Find project folder
3. Upload test document
4. Complete → Confirm workflow
5. Verify state changes

Troubleshooting

Module Installation Fails

  • Check installation order
  • Verify dependencies installed
  • Check Odoo logs: docker-compose logs odoo

Enterprise Modules Missing

  • Verify enterprise addons path in odoo.conf
  • Check Documents module installed
  • Restart Odoo: docker-compose restart odoo

Slow Performance

  • Set workers=0 in odoo.conf during installation
  • Increase after all modules installed
